- **AgentNod hint:** while a coding agent runs in one of your projects, Overhead points to AgentNod, which lets you answer the agent's permission prompts from a notification or your phone. It only shows when AgentNod isn't installed, and the ✕ hides it for good, like the DevSweeper hint.

Install with Homebrew: `brew install --cask dimeloper/tap/overhead`, or `brew upgrade --cask overhead` if you already have it.
