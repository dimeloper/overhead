The first downloadable build. Open the DMG and drag Overhead to Applications. It is signed and notarised by Apple and runs on macOS 14 or later, on Apple silicon and Intel.

What it does:

- **Menu bar:** CPU and memory as percentages, updated every second, plus battery time at your current pace while unplugged.
- **Projects:** memory and CPU added up by the git checkout they run from, worktrees included. A coding agent's own tools are counted under the agent instead of passing for your dev servers.
- **Keep awake:** Off, On or Auto. Auto holds while a build or agent is actually working.
- **Ports and simulators:** dev servers listening in your projects, and booted simulators with what they cost, each with a Stop or Shut Down button.
- **Park:** stop a project's servers and its simulators and keep a setup sheet to come back to. It never stops coding agents and never touches files.

Install with Homebrew: `brew install --cask dimeloper/tap/overhead`
