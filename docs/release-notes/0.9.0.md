- **Updates itself.** Overhead checks for a new version once a day. When there is one, an "Update to …" button
  appears at the bottom of the popover; Settings has "Check for Updates…" and a switch to turn checking off. Updates
  are signed, and Overhead installs only one signed with its own key. This is the last version you need to install
  by hand.
- **The DevSweeper hint opens DevSweeper on your parked project**, once DevSweeper supports it. Older versions of
  DevSweeper open as before.

Install with Homebrew: `brew install --cask dimeloper/tap/overhead`, or `brew upgrade --cask overhead` if you already have it.
